# Personal Gemini Journal

An authenticated AI journal mentor built with Firebase Authentication, Firestore, and the Gemini API.

## Features
- **User Authentication:** Firebase Google Sign-In.
- **AI Mentorship:** Multi-turn contextual reflection using the Gemini API.
- **Isolated Data Storage:** Cloud Firestore structured with per-user document security rules.

## Local Setup
1. Clone this repository.
2. Run `npm install`.
3. Add your `GEMINI_API_KEY` into `.env`.
4. Run `npm start`.
5. Visit `http://localhost:8080`.
